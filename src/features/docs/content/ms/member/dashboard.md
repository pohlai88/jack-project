# Papan pemuka

Dashboard ialah pusat utama anda. Ia memaparkan statistik penting, tindakan pantas dan aktiviti terkini supaya anda kekal mengikuti perkara yang penting.

## Kad statistik

Di bahagian atas papan pemuka, anda akan melihat kad ringkasan dengan metrik utama yang relevan kepada tenant. Kad ini memberi gambaran pantas tentang aktiviti dan item tertunda.

> **Tip:** Klik kad untuk pergi ke bahagian berkaitan.

Contoh rupa kad statistik:

```preview
component: StatCard
props: { "value": 12, "label": "Team members" }
```

## Tindakan pantas

Tindakan pantas membolehkan anda memulakan tugasan biasa tanpa meninggalkan papan pemuka:

- Lihat ahli pasukan
- Buka **AI Assistant** untuk soalan
- Pergi ke tetapan admin jika anda mempunyai kebenaran

Gunakannya untuk mencapai aliran kerja yang paling kerap digunakan.

## Suapan aktiviti

Suapan aktiviti menunjukkan peristiwa terkini yang relevan kepada anda, seperti:

- Ahli baharu menyertai tenant
- Perubahan konfigurasi
- Notifikasi sistem

Tatal untuk melihat lagi. Gunakan feed untuk mengetahui perubahan dan tindakan susulan.

### Memanfaatkan papan pemuka

1. **Semak statistik** — Lihat metrik utama dengan cepat untuk memahami keadaan semasa.
2. **Gunakan tindakan pantas** — Lompat ke tugasan biasa tanpa membuka banyak menu.
3. **Semak feed** — Imbas aktiviti terkini untuk perkara yang memerlukan perhatian.

> **Petua:** Lawati papan pemuka dengan kerap untuk kekal maklum tentang aktiviti tenant.
