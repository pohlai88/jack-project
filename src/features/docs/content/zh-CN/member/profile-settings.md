# Profile & Settings

profile 决定你在 Afenda 中如何展示 — 在 directory、People Finder，以及 manager 和同事面前。Settings 控制 integrations、timezone 和联系方式。

## 编辑 profile

1. 从用户菜单或导航进入 **Profile** 或 **Settings**。
2. 根据需要更新 **display name**、**job title** 和 **bio**。
3. 保存更改。更新会反映在搜索和 directory 中。

保持 title 和 bio 最新，可以让他人按正确的技能和角色找到你。

## Avatar

- **Upload** — 使用清晰头像或专业图片。
- **Remove** — 清除 avatar，改用首字母或默认头像。
- **Crop** — 某些流程允许保存前裁剪。

> **提示：** 易识别的 avatar 有助于 People Finder、directory 和 feedback/recognition。

## 连接 GitHub

关联 GitHub 帮助 Afenda 了解你的技术活动，并可能改善技能和项目建议。

1. 在 **Settings** 或 **Integrations** 中找到 **GitHub**。
2. 点击 **Connect** 并在 GitHub 中授权 Afenda。
3. 关联后，profile 可能显示相关 repo 或活动，具体取决于 tenant 设置。

你可以随时在同一位置断开 GitHub。

## 连接 LinkedIn

连接 LinkedIn 可以用经历和技能丰富你的 profile。

1. 在 **Settings** 或 **Integrations** 中找到 **LinkedIn**。
2. 点击 **Connect** 并完成 LinkedIn 授权。
3. 使用的数据（如 headline、skills）取决于 tenant 配置。

如果不再需要链接，可在同一 integration 屏幕断开。

## Timezone

设置 timezone 可以确保：

- 会议时间和提醒以你的本地时间显示。
- 1:1 和 deadline 日程正确。

1. 在 **Settings** 中打开 **Preferences** 或 **Profile**。
2. 从 dropdown 选择 **Timezone**。
3. 保存。日历和通知时间会使用该 timezone。

## Pronouns

你可以选择设置 **pronouns**（例如 she/her、he/him、they/them），让平台和他人正确称呼你。它通常位于 **Profile** 或 **Preferences** 中，并且是可选项。

## Personal email

如果 tenant 允许，你可以在工作 email 之外添加 **personal email**。它会根据组织政策用于账户恢复或通知。请在 **Settings → Account** 或 **Profile** 中查找该字段。

### 摘要

| 设置                     | 位置            | 用途                              |
| ------------------------ | --------------- | --------------------------------- |
| Display name, title, bio | Profile         | 你在 directory 和搜索中的展示方式 |
| Avatar                   | Profile         | UI 和 feedback 中的识别           |
| GitHub                   | Integrations    | 技术上下文和建议                  |
| LinkedIn                 | Integrations    | 经历和技能上下文                  |
| Timezone                 | Preferences     | 会议和提醒的正确时间              |
| Pronouns                 | Profile         | 产品中的正确称呼                  |
| Personal email           | Account/Profile | 恢复账户和可选通知                |

## 搜索可见性

当你更新 profile（bio、location、timezone 或其他设置）时，Afenda 会自动刷新你的 **search profile**，确保 People Finder 结果保持最新。profile 越完整，他人越容易为合适的机会找到你。

同样，如果 admin 从 integrations 同步数据，例如 GitHub 同步你的 repo，你的 search profile 会自动更新，并在 evidence 列表中出现一条 **evidence record**，显示同步了哪些内容。

> **提示：** 当 role 或位置发生变化时，请更新 profile 和 timezone，确保建议和排程保持准确。
