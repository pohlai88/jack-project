# 成员指南概览

作为**成员**，你可以管理个人资料、查看仪表盘，并与 AI 助手交互。本指南介绍每位平台成员可用的能力。

## 你可以做什么

| 区域           | 可用内容                       |
| -------------- | ------------------------------ |
| **仪表盘**     | 统计、快速操作、活动摘要       |
| **资料与设置** | 编辑个人资料、头像、时区和偏好 |
| **AI 助手**    | 通过对话获取帮助、搜索和建议   |

## 快速链接

- [仪表盘](/docs/member/dashboard) — 你的起点：统计和快速操作
- [资料与设置](/docs/member/profile-settings) — 保持 profile 最新
- [AI 助手](/docs/member/ai-assistant) — 用自然语言获得帮助和搜索

> **提示：** 收藏仪表盘，并使用 AI 助手 快速获取答案和指引。
