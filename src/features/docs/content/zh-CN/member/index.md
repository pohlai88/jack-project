# Member 指南概览

作为 **member**，你可以管理 profile、查看 dashboard，并与 AI assistant 交互。本指南介绍每位平台 member 可用的能力。

## 你可以做什么

| 区域                   | 可用内容                             |
| ---------------------- | ------------------------------------ |
| **Dashboard**          | 统计、快速操作、活动摘要             |
| **Profile & Settings** | 编辑 profile、avatar、timezone、偏好 |
| **AI Assistant**       | 通过 chat 获取帮助、搜索和建议       |

## 快速链接

- [Dashboard](/docs/zh-CN/member/dashboard) — 你的起点：统计和快速操作
- [Profile & Settings](/docs/zh-CN/member/profile-settings) — 保持 profile 最新
- [AI Assistant](/docs/zh-CN/member/ai-assistant) — 用自然语言获得帮助和搜索

> **提示：** 收藏 Dashboard，并使用 AI Assistant 快速获取答案和指引。
