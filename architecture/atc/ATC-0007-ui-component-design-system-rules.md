# ATC-0007: UI Component and Design System Rules

## Acceptance Criteria

- Shared UI primitives remain under stable `@/shared/components/ui` subpaths.
- Feature-specific UI composition remains owned by the feature.
- Tailwind v4 theme tokens remain CSS-first.
- Reusable primitives preserve shadcn/Radix accessibility patterns.
- Server/client boundaries are protected by feature-owned client glue where needed.
