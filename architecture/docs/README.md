# Deprecated Engineering Docs Tombstone

`architecture/docs/` is deprecated and is not an engineering authority.

Historical template-era docs were removed after durable rules were promoted into the current authority chain:

- [Doctrine](../doctrine) defines current rules and operating principles.
- [ADR](../adr) records consequential architecture decisions.
- [ATC](../atc) defines architecture test cases and acceptance checks.

If a removed topic is needed, recover it from git history, verify it against current code, and promote repo-true content into doctrine, ADRs, or ATCs before relying on it.

Do not recreate broad reference docs in this folder.
