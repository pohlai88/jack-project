# 0001: Documentation Authority

## Rule

Current engineering authority lives in `architecture/doctrine/`, `architecture/adr/`, and `architecture/atc/`.

## Implications

- Treat `architecture/docs/` as historical reference unless a rule has been promoted.
- Capture long-lived operating rules in `architecture/doctrine/`.
- Capture consequential architecture choices in `architecture/adr/`.
- Capture enforceable checks and acceptance criteria in `architecture/atc/`.
