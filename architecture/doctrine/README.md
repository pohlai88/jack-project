# Engineering Doctrine

This directory contains current engineering rules and operating principles.

`architecture/docs/` is retained only as a deprecated tombstone. Durable rules should be promoted here, consequential architecture decisions should be captured in `architecture/adr/`, and enforceable acceptance checks should live in `architecture/atc/`.
