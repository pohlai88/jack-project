# 个人资料设置

你的 **profile** 决定你在 Afenda 中如何呈现给同事：People Finder、projects、1:1 和 directory 都会使用它。本指南说明如何编辑 profile 并设置偏好，让平台更适合你。

---

## 在哪里编辑 profile

- 从 **My View**，在 sidebar 中打开 **Profile** 或 **Profile settings**，也可以使用 header 中的 **account/avatar menu** 并选择 “Profile” 或 “Settings”。
- 首次登录时，你也可能从 “Complete your profile” 提示进入 profile 页面。

profile 表单通常分为 **Basic info**、**Links**（GitHub、LinkedIn）、**Preferences**（timezone、locale）以及有时的 **Privacy**。

---

## 基本信息

这些字段定义你在 tenant 中的身份。

| 字段       | 用途                                                                            |
| ---------- | ------------------------------------------------------------------------------- |
| **Name**   | 全名或显示名。显示在搜索、directory 和 org chart 中。                           |
| **Title**  | 职位或角色，例如 “Software Engineer”、“Product Manager”。帮助他人理解你的职责。 |
| **Bio**    | 关于你、关注领域或工作方式的简短说明。可选，但对 People Finder 和介绍很有用。   |
| **Avatar** | 头像。帮助在列表、1:1 和 feedback 中识别你。                                    |

### 更新基本信息

1. 打开 **Profile** 或 **Profile settings**。
2. 根据需要编辑 **Name** 和 **Title**。
3. 在文本框中添加或修改 **Bio**。
4. 对于 **Avatar**，使用上传或 “Change photo” 控件，并按支持的格式和大小说明操作。
5. 保存，例如 **Save** 或 **Update profile**。更改会在应用中生效。

> **提示：** 清晰、最新的 title 和简短 bio 能帮助同事在 People Finder 中找到你，并理解你可以提供的帮助。

---

## 连接 GitHub 和 LinkedIn

关联外部账户可以帮助 Afenda 以及可选 AI 理解你的技能和职业信息。

- **GitHub** — 连接你的 GitHub profile。根据 tenant 配置，可用于 evidence、skills inference 或 portfolio 链接。
- **LinkedIn** — 连接你的 LinkedIn profile。通常用于职业身份和可选的技能/经验信号。

### 如何连接

1. 在 profile 中找到 **Links** 或 **Connected accounts** 部分。
2. 点击 **GitHub** 或 **LinkedIn** 旁边的 **Connect**。
3. 在弹窗或重定向中完成 OAuth 流程，授权 Afenda 访问请求的数据。
4. 授权后，账户会显示为 “Connected”，并可能出现 **Disconnect** 选项。

断开连接会移除该链接以及从该账户拉取的数据；你的 profile 和 skills 不会被删除，但依赖该连接的 evidence 或 inference 可能会受 tenant 规则影响。

---

## Timezone 和位置

设置 **timezone** 和可选的 **location** 有助于：

- 安排 1:1 和会议。
- 在应用中按本地时区显示时间。
- 支持使用位置的筛选或分析（如果 tenant 使用）。

### 步骤

1. 在 profile 或 **Preferences** 中找到 **Timezone**。
2. 从 dropdown 选择 timezone，例如 “Europe/Madrid”、“America/New_York”。
3. 如果有 **Location**（城市、国家或地区），按需要填写。
4. 保存。应用会在日期/时间显示和排程中使用这些设置。

> **提示：** 使用与你实际工作地点匹配的城市或地区，确保会议时间和提醒正确。

---

## Personal email 和 pronouns

- **Personal email** — 如果 profile 有 “Personal email” 或 “Contact email” 字段，且它与登录 email 分离，你可以设置用于联系或恢复账户。是否对他人显示取决于 tenant 隐私设置。
- **Pronouns** — 如果 tenant 支持 **pronouns**（例如 “she/her”、“he/him”、“they/them”），你可以在 profile 中选择或输入。它们通常显示在 directory、1:1 和 feedback 中姓名旁边，以支持包容性沟通。

这些字段通常在同一个 profile 表单中的 “Contact” 或 “Identity” 下编辑，然后保存。

---

## 保存后

- **name**、**title**、**avatar** 和已设置的 **pronouns** 会出现在 directory、org chart、People Finder，以及你发送或接收 feedback 时。
- **GitHub/LinkedIn** 链接可能用于 evidence 和 skills，具体取决于配置。
- **Timezone** 和 **location** 用于排程和显示。
- 当 role、关注领域或偏好变化时，请重新访问 profile，保持平台信息准确且对你和团队有用。

关于应用内移动方式，请参阅 [导航与视图](/docs/getting-started/navigation)。关于 member 专属功能（skills、OKRs、learning），请使用 docs 的 **Member** 部分。
