## Choose the right truth surface

<Tabs items={["Curated", "Generated Evidence", "API", "LLM"]}>
  <Tab>

Curated pages establish doctrine and product meaning. They explain Afenda as a Truth Engine but do not replace manifest-backed evidence.

  </Tab>
  <Tab>

Generated evidence pages are deterministic outputs from docs manifests. Use them when changing routes, permissions, workflows, APIs, errors, or troubleshooting contracts.

  </Tab>
  <Tab>

The OpenAPI reference renders documented HTTP interface truth through Fumadocs OpenAPI. Use it for request/response-oriented API inspection.

  </Tab>
  <Tab>

LLM routes expose the documentation corpus as machine-readable Markdown so agents can read the same truth surfaces as humans.

  </Tab>
</Tabs>
