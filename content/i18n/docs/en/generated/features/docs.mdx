## APIs

- `GET /llms.txt` - Expose the Fumadocs page index for LLM-friendly discovery. Optional `locale` query selects the language tree (default `en`).
- `GET /llms-full.txt` - Expose all documentation pages as clean Markdown for LLM consumption. Optional `locale` query selects the language tree (default `en`).
- `GET /llms.mdx/[locale]/docs/[[...slug]]` - Expose one locale-aware documentation page as clean Markdown for LLM consumption.
- `GET /api/search` - Expose locale-aware Fumadocs search results from the generated documentation source.
- `GET /rss.xml` - Expose an RSS feed for generated documentation evidence pages.
- `GET /[locale]/og/docs/[...slug]` - Generate Open Graph images for documentation pages (next/og + Fumadocs UI template). Static path ends with image.png.

## Errors

- `AFD-DOCS-CONTRACT` - Docs contract validation failed: Fix manifest IDs, owners, routes, permissions, APIs, errors, or troubleshooting references.
- `AFD-DOCS-FEEDBACK-VALIDATION` - Docs feedback validation failed: Submit feedback only for canonical /docs pages with a supported opinion and bounded message.
- `AFD-DOCS-FEEDBACK-ORIGIN` - Docs feedback origin rejected: Ensure the request Origin matches the deployment Host or X-Forwarded-Host.
- `AFD-DOCS-FEEDBACK-RATE-LIMIT` - Docs feedback rate limit exceeded: Wait for the feedback submission window to reset before retrying.
- `AFD-DOCS-FEEDBACK-CONTEXT` - Docs feedback request context unavailable: Confirm the deployment provides AUTH_SECRET and enough request headers to derive a rate-limit key.
- `AFD-DOCS-FEEDBACK-STORAGE` - Docs feedback storage failed: Check database connectivity and the docs_page_feedback_events migration state.
