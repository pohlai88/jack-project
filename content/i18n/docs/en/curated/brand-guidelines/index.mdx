## Thesis

Afenda brand marks identify governed truth surfaces. Use them as brand identity anchors only; do not use the lynx as a
functional UI icon, status glyph, CTA marker, settings icon, or feature illustration.

## Operational Implication

Use root-relative public paths. Do not import from the user's Downloads directory, Figma node URLs, or generated report
artifacts.

```tsx
export function ProductNavBrand() {
  return <AppLogo placement="nav" />;
}
```

Use placement semantics instead of raw asset variants.

```tsx
<AppLogo placement="sidebar" showText={false} />
<AppLogo placement="auth" showText={false} href={null} />
<AppLogo placement="error" showText={false} href={null} />
```

For CSS backgrounds, keep the same public contract:

```css
.afenda-launch-tile {
  background-image: url('/brand/afenda/afenda-icon-gradient-bg.svg');
}
```

### Frontend placement matrix

| Placement                   | Integration point                              | Size target           | Semantic placement / variant            | How to apply                                                                                                          |
| --------------------------- | ---------------------------------------------- | --------------------- | --------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Landing navbar              | `AppLogo placement="nav"`                      | 64 px rendered height | `combinedLockup` / `combinedLockupDark` | Set `size="xl"`, set `allowTenantLogo={false}`, keep `tagline` off; `landing.css` enforces final rendered dimensions. |
| Landing footer              | `AppLogo placement="footer"`                   | 64 px rendered height | `combinedLockup` / `combinedLockupDark` | Set `size="xl"`, set `allowTenantLogo={false}`, keep `tagline` off; `landing.css` enforces final rendered dimensions. |
| App sidebar expanded        | `AppLogo placement="sidebar"`                  | 32 px                 | tenant logo or `inline` / `inlineDark`  | Unframed mark; tenant logo may override in tenant-scoped chrome.                                                      |
| Collapsed sidebar           | `AppLogo placement="sidebar" showText={false}` | 32 px                 | tenant logo or `inline` / `inlineDark`  | Keep tenant fallback within max `32x32` without forced crop.                                                          |
| Mobile drawer title         | `AppLogo placement="sidebar"`                  | 32 px                 | tenant logo or `inline` / `inlineDark`  | Match sidebar identity and sizing.                                                                                    |
| Auth entry pages            | `AppLogo placement="auth"`                     | 64 px                 | `appTileLight` / `appTileDark`          | Framed tile is allowed for splash brand context.                                                                      |
| Tenant login                | `AppLogo placement="tenant-login"`             | 64 px                 | tenant logo, fallback app tile          | Prefer tenant logo; fallback may be framed.                                                                           |
| Metadata favicon            | root metadata                                  | browser controlled    | `appTileGradient`                       | Use icon outputs in `/public/icons` and manifest metadata.                                                            |
| Docs shell                  | Fumadocs nav title                             | 24 px                 | `inline` / `inlineDark`                 | Keep mark unframed and compact.                                                                                       |
| Error / not-found states    | global error and 404 page                      | 64 px                 | `monoBlack` / `monoWhite`               | Brand anchor only; do not replace functional status icons.                                                            |
| Functional UI icons         | search, CTA, status, feature, settings         | normal UI size        | Lucide or semantic icon                 | Never use Afenda brand marks as functional icons.                                                                     |
| Social / launch preview     | future OG, launch, social preview work         | 128 / 256 px          | `appTileGradient`                       | Use only for high-signal launch surfaces.                                                                             |
| Print and single-ink output | print, stamp, engraving, embossing             | production-specific   | mono variants                           | Confirm physical proof before production.                                                                             |

Theme-dependent app tiles must render deterministically. Prefer CSS visibility (`afenda-theme-light` /
`afenda-theme-dark`) over reading the active theme during server render.

### Mark meaning

The Afenda mark represents an intelligent observer inside a bounded truth system. The circle is the governed system
field. The lynx is precision, clarity, and silent intelligence beyond noise. The bead sequence is the verification
chain. The blue to violet flow represents raw signal becoming verified canonical truth.

### Digital color system

| Role           | Digital reference | OKLCH reference       | Meaning                  |
| -------------- | ----------------- | --------------------- | ------------------------ |
| Raw Signal     | `#2563EB`         | `oklch(62% 0.18 250)` | Precise input signal     |
| Processing     | `#5B21B6`         | `oklch(68% 0.16 275)` | Governed transformation  |
| Verified Truth | `#9333EA`         | `oklch(58% 0.20 310)` | Resolved canonical truth |

### Print color system

<Callout title="Production note" type="warn">
  CMYK and Pantone values are production starting points, not guaranteed visual matches. Confirm with the printer, paper
  stock, lighting condition, and physical proof before final production.
</Callout>

| Role                  | HEX       | CMYK baseline   | Pantone Coated   | Pantone Uncoated |
| --------------------- | --------- | --------------- | ---------------- | ---------------- |
| Raw Signal Blue       | `#2563EB` | `C85 M65 Y0 K0` | `Pantone 2728 C` | `2728 U`         |
| Processing Indigo     | `#5B21B6` | `C80 M95 Y0 K0` | `Pantone 2736 C` | `2736 U`         |
| Verified Truth Purple | `#9333EA` | `C60 M85 Y0 K0` | `Pantone 2665 C` | `2665 U`         |

Premium editorial alternatives: use `Pantone 7687 C` for a deeper institutional blue and `Pantone 2090 C` for a
richer violet.

Print controls:

- Keep total ink coverage at or below `280%`.
- Avoid `C + M > 180%` in violet blends because the gradient can become muddy.
- Avoid black ink in the core gradient unless producing the dark or monochrome variant.
- Use 300 DPI minimum source artwork and prefer a 16-bit gradient source for large-format output.
- Add 1-2% grain when a vendor confirms visible gradient banding.
- Use coated values as the baseline, Pantone U for uncoated stock, slight contrast boost for matte stock, and avoid
  fine gradient transitions on textured stock.
