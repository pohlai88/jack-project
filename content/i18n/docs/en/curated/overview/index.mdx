## Thesis

Curated pages orient readers; generated evidence pages hold governed product truth.

## Model

Curated pages explain the documentation system. They do not define product truth.
Authoritative evidence lives under generated feature, workflow, permission, API, error, and troubleshooting pages.

## How to read this documentation

Use curated pages for orientation. Use generated pages for proof.

The docs tree separates three responsibilities:

- **Curated context** — narrative guidance and system orientation.
- **Generated evidence** — product truth extracted from governed definitions.
- **Operational surfaces** — APIs, workflows, troubleshooting, and machine-readable exports.

## Operational implication

If a page cannot be traced to a manifest, runtime contract, or source API, it must not be treated as authoritative.
